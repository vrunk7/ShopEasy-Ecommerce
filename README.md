# ShopEasy – E-commerce Single Page Application

ShopEasy is an e-commerce Single Page Application developed using React. It allows users to browse products, filter items, manage a shopping cart, and place orders through a simple and user-friendly interface.

## Features

- **Home Page:** Displays featured products and product categories.
- **Product Listing:** Browse products and filter them by category and price.
- **Product Details:** View individual product information.
- **Shopping Cart:** Add, remove, and update product quantities.
- **Cart Persistence:** Cart data is maintained using localStorage.
- **Checkout:** Enter shipping details with form validation.
- **Order Confirmation:** Displays order confirmation after checkout.
- **Order History:** View previously placed orders and their details.
- **Responsive Design:** User-friendly layout for different screen sizes.
- **404 Page:** Handles invalid routes.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd ShopEasy-Ecommerce
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.
